# 💰 Smart Expense Tracker with AI Chatbot

Managing finances shouldn’t feel like a chore.  
This project reimagines expense tracking as an **interactive, user-friendly experience** by combining a powerful MERN-based backend with an **AI-powered chatbot** that actively assists users in managing their finances.

Built collaboratively, this Expense Tracker not only records transactions but also **guides users, answers queries, and simplifies financial planning in real time**.

---

## 🎯 Project Motivation

Traditional expense trackers focus only on recording data.  
Our goal was to go a step further:

- Make expense tracking intuitive
- Help users *understand* their spending
- Enable real-time interaction with financial data
- Turn static numbers into actionable insights

---

## 🚀 Features

### 🔐 Seamless Authentication
- Secure user registration and login
- Personalized expense data per user

### 📊 Insightful Dashboard
- Clear overview of:
  - Total income
  - Total expenses
  - Remaining balance

### 💸 Smart Transaction Management
- Add new transactions
- Edit existing entries
- Delete unwanted records
- Categorized expense tracking

### 📈 Data-Driven Visualization
- Interactive graphs and charts
- Analyze spending patterns over time
- Better financial awareness

### 🤖 AI-Powered Chatbot
- Acts as a virtual finance assistant
- Answers user queries about expenses
- Guides users on budgeting and spending habits
- Makes financial tracking more engaging

---

## 🛠 Tech Stack

### Backend
- Node.js  
- Express.js  

### Database
- MongoDB  

### Frontend
- JavaScript  
- HTML  
- CSS  

### AI / Chatbot
- JavaScript-based chatbot logic
- Integrated with expense data for real-time responses

---

## 🧱 System Overview

1. User logs in securely
2. Transactions are stored in MongoDB
3. Dashboard fetches and displays insights
4. Charts visualize income vs expenses
5. Chatbot interacts with stored data to guide users
